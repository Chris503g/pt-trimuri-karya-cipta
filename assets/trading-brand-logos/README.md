# General Trading brand logo library

This folder holds 164 individual WebP brand images extracted from the **user-supplied** *Trading Customers (1).pdf* reference. Each WebP has a white background and is sized 480 × 220 px for consistent presentation. Existing SVG brand marks elsewhere in the repository are retained and take priority where already displayed; this set is used for the remaining 118 website placeholders.

The logo images are reproduced from TKC's reference material and have **not** all been checked against each manufacturer's most recent official branding. Names and trademarks belong to their respective owners. Listing these names does not assert exclusive distributorship, official partnership, or guaranteed stock availability.

The site remains a static HTML/CSS/JS site. Replace an individual brand card's image URL in `index.html` when a higher-quality or updated logo becomes available.
